# Sykkel Kompaniet – demo

Dette er en enkel statisk prototype laget for å vise kunde retning og uttrykk.

## Åpne demoen
Dobbeltklikk `index.html`.

## Innhold
- Responsiv header/nav
- Hero
- Kategorier
- Produkter
- Produktsøk
- Enkel demo-handlekurv
- Merker
- Nyhetsbrev
- Footer

## Viktig
Produktdata, priser, kontaktinfo og funksjoner er eksempeldata.
For produksjon bør dette bygges videre i f.eks. Next.js med ekte produktdatabase, lager, checkout og betaling.
